# CW1-Webpage
Evaluating and updating a webpage

## Assignment Tasks:
- Create a profile site, using GitHub for version control, that can be used to support you in building your portfolio of work and applying for placements:
Pages required
  - About you- include name, year of study and award you are studying for. You must also include a suitable image of you or a placeholder image if you prefer. 
  - Technical interests (pertinent to the area of work you are interested in)- note this is not a tutorial section, but should contain a title of the technical interest and a 1 - 2 paragraphs about your interest. An appropriate image or placeholder image should be included.
  - Portfolio - relevant projects or work you have completed. Users have the option of getting a pop-up window with further information or clicking on a link to go to the project details page (you do not need to include actual projects i.e. project artefacts. A holding page is fine)
  - Project details page - details about the project or work
  - Contact Me page - a form for visitors to submit their contact details and comments or questions (note this is client side only i.e. only using HTML, CSS and JavaScript)
- Carry out and submit the results of a heuristic evaluation of your completed site using Nielsen's heuristics 
  - You are required to use the heuristic evaluation templateDownload heuristic evaluation template provided
  - You must not involve anyone in the usability evaluation of your site. Doing so may constitute an academic offence.
- Demonstrate through at least one automated conformance test that you focussed on accessibility in your development work and that the final profile site conforms to level AA of the WCAG
  - You must use the WAVE pluginLinks to an external site. for your conformance test and no other technology or techniques.
  - You must not involve anyone in the accessibility evaluation of your site. Doing so may constitute an academic offence.
---
## You are also marked on:
- Your use HTML, CSS and JavaScript that you have created. You must not use templates or libraries.
- Your use of software versioning using GitHub- you must make regular contributions to your repository on GitHub
- Your site being developed over time on GitHub- you must make use of GitHub in your development work.

## What to submit and how
- GitHub:
  - You must work on your profile site on the GitHub repository you are provided with
- Canvas: In one upload, you are required to submit:
  - A zip file of your profile site downloaded from Github,
  - Your accessibility report (in doc, docx, rtf or pdf) - must not be in zip file
  - Your usability report (in doc, docx, rtf or pdf) - must not be in zip file

Check your submission after you upload it. It is your responsibility to make sure the correct files have been uploaded and that they conform to the requirements above. If files are not present on Canvas, they will not be marked.
